# 自定义积分榜接口说明

2026-11-19，按用户要求移除排行榜配置键及按配置存档代码。游戏配置和计分公式仍由 game 模块负责，排行榜只接收用户名和最终分数。

## 接口

```c
int saveCustomScore(const char name[], int finalScore);
int resetCustomRankPage(void);
int updateCustomRankPage(void);
void drawCustomRankPage(Font font);
```

saveCustomScore 仅在自定义通关时调用一次：1 保存成功，0 未刷新个人最高分或未进入前五，-1 文件错误。每人保留最高分，同分保留原顺序。读取和保存不在绘制函数中执行。

resetCustomRankPage 读取榜单并选中自定义选项；1 成功，-1 文件错误。主菜单使用 resetRankPage 默认进入初级；顶部依次为初级、中级、高级、自定义，统一使用 updateRankPage/drawRankPage 调度。

## 存档

独立 custom_ranks.txt，每行只有用户名和分数：

```text
ZhangQi 279
```

不保存行列、预览时间、公式版本或耗时，不再使用配置转换函数。文件保存前五名；普通 ranks.txt 保持不变。旧本地存档已一次性转换，原件留在本次任务的积分榜移除配置目录，源码不保留旧配置格式解析逻辑。

自定义榜只展示名次、用户名、分数，底部仅保留返回，没有配置切换和重新读取按钮。存档属于运行数据，不提交到 Git。
